# SolaTrip · página de servicio

Página estática (HTML, CSS y JavaScript, sin compilar) publicada en Cloudflare Pages.

## Estructura
- `index.html`: página principal.
- `aviso-privacidad.html`: aviso de privacidad.
- `css/styles.css`: estilos (colores y letras de la marca al inicio, en `:root`).
- `js/main.js`: menú de celular y formulario. El número de WhatsApp está en `WHATSAPP_NUMBER`.
- `img/`: fotos e imágenes del PDF de regalo.
- `fonts/`: Caveat y Poppins alojadas en el sitio (sin Google Fonts).
- `regalo/`: PDF del itinerario de regalo de Suiza y Escocia.
- `_headers`: cabeceras de seguridad y caché para Cloudflare.

## Publicar cambios
Cloudflare Pages publica solo cada vez que se sube un cambio a la rama principal del repositorio. Sin comando de compilación; carpeta de salida: la raíz.
